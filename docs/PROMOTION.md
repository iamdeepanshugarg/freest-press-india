# Promotion Plan

## Launch message

Free Press India is a transparent, community-maintained directory of Indian public-interest, independent, regional, investigative, data, environmental, and fact-checking journalism sources.

The goal is not to rank outlets politically. Every entry has evidence fields, ownership/funding notes, caveats, review status, and contribution rules.

## Places to share

- Reddit: r/india, r/IndianModerate, r/journalism, state subreddits
- LinkedIn: journalists, media literacy educators, journalism schools
- X/Twitter: tag listed outlets and ask for corrections
- GitHub: submit to awesome lists and civic-tech lists
- Colleges: journalism/media-literacy groups

## Outreach template

Subject: Request for feedback: Free Press India directory

Hello,

I am maintaining an open directory of Indian public-interest journalism sources. Your outlet/resource is listed with ownership/funding, caveats, and evidence links. Could you review the entry and suggest corrections through GitHub issues or pull requests?

Project: https://github.com/iamdeepanshugarg/freest-press-india

Thank you.

## Success metrics

- 100 verified entries
- 10 community contributors
- 0 unsourced watchlist claims
- monthly review cadence
- translations in at least 3 Indian languages
