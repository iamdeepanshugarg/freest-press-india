# Media Literacy Tools

Use tools as aids, not as final truth.

## Claim search

- Google Fact Check Explorer: search published fact-checks by claim/topic.
- Fact-checking outlets: Alt News, BOOM, Factly, Digiteye, Newschecker, Vishvas News.

## Image/video verification

- TinEye reverse image search.
- Google Lens / reverse image search.
- InVID-WeVerify plugin for video keyframes.
- Check upload date, earliest appearance, location clues, weather, signage, language, and shadows.

## Reading checklist

```txt
[ ] What exactly is being claimed?
[ ] Who is making the claim?
[ ] Is there primary evidence?
[ ] Is the image/video old or from another location?
[ ] Does the outlet correct mistakes publicly?
[ ] Are opinion and news clearly separated?
[ ] Who funds or owns the outlet?
```
