# Source Review Checklist

Use this before merging a source.

```txt
[ ] Official website loads.
[ ] About/team page exists or absence is noted.
[ ] Ownership/funding is filled or marked needs_review.
[ ] Correction policy is filled or marked unknown.
[ ] Methodology page is checked for fact-checkers.
[ ] IFCN status is checked for fact-checkers.
[ ] Newsletter/RSS availability is checked.
[ ] At least one original story or public-interest example is linked.
[ ] Caveats are neutral and evidence-backed.
[ ] Last reviewed date is updated.
```
